Tokens

Design tokens

Design tokens are the named values behind every color, space and corner in Campus, like --primary-base or --space-md. Everyone uses the same names, so a change in one place shows up everywhere.

1Design in Figma

Designers pick colors and sizes from the Campus variables in the Figma library.

→
2Tokens

Each variable becomes a named token in campus-tokens.css and campus-tokens.json.

→
3Prototypes and code

Prototypes and product code use those same names with var(--token), so they match the design.

    Course Pro

    Course Pro is where lessons and courses get built. Its design stays structured and predictable, so authors can focus on their content instead of the tool.

    /

    One mode, two layers. Course Pro has a single Default mode. A primitive palette holds the raw colors, and semantic tokens like primary-600 point to it. Each swatch shows both, so you can see where every color comes from.

    01Colors

    Brand, status and the content colors that tell authors what kind of thing they’re looking at. Click any swatch to copy its hex.

    02Typography

    Poppins for headings, Inter for body copy and controls, Space Grotesk for code, and Boldonse for display moments.

    03Shape and borders

    Corner radius, border widths and the three border colors used across cards, inputs and rows.

    04Spacing

    Padding and gap tokens, from 2px to 72px.

    05Components

    Live previews built from the component tokens in the files. Hover and click them to see their states.

    06All tokens

    Every semantic token with its value, what it points to and its description. Turn on primitives to include the raw palette.
